# ⭐ Task 1: Print Numbers 1 to N

## 🔍 Overview
* A program that prints all numbers from 1 to N, where N is entered by the user.

## 🎯 Objective
* To learn how to use the for loop to perform repetitive tasks efficiently.

## ✅ Output
* A sequential list of integers starting from 1 up to the user's input N.

## ✍️ Learning Outcomes
* Understanding how to initialize a loop and set a stop condition.

## 🔍 Overview

## 🎯 Objective
