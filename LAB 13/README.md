# 💻 CS-1101 Programming Fundamentals – Lab 13

This lab focuses on understanding and implementing pointers in C++. Through six practical tasks, students will explore pointer declaration, dereferencing, pointer arithmetic, pointer-based function arguments, and special pointer types like nullptr and void*.

---

# ⭐ Task 1: Pointer to Integer
## 🔍 Overview

This program demonstrates how to declare a pointer, assign it the address of an integer variable, and use it to access the value.

## 🎯 Objective

To understand how pointers store memory addresses and how to access values using dereferencing.

## ✔️ Output

Displays the value of the integer using the pointer.

## ✍️ Learning Outcomes

- Declare and initialize pointers
- Use the address-of (&) and dereference (*) operators
- Understand basic pointer syntax

---

# ⭐ Task 2: Modify Value via Pointer
## 🔍 Overview

This program shows how to change the value of a variable using its pointer.

## 🎯 Objective

To demonstrate how pointers can be used to modify variable values directly.

## ✔️ Output

Displays the modified value of the variable after pointer manipulation.

## ✍️ Learning Outcomes

- Modify variables through pointers
- Understand memory-level manipulation
- Reinforce dereferencing usage

---

# ⭐ Task 3: Array Access via Pointer Arithmetic
## 🔍 Overview

This program uses a pointer to access and display elements of an integer array using pointer arithmetic.

## 🎯 Objective

To practice traversing arrays using pointers instead of array indexing.

## ✔️ Output

Displays each element of the array using pointer arithmetic.

## ✍️ Learning Outcomes

- Use array names as pointers
- Apply pointer arithmetic (ptr++)
- Traverse arrays using pointers

---

# ⭐ Task 4: Swap Using Pointers
## 🔍 Overview

This program swaps two numbers using a function that takes pointers as arguments.

## 🎯 Objective

To understand call-by-reference using pointers in function arguments.

## ✔️ Output

Displays values before and after swapping.

## ✍️ Learning Outcomes

- Pass pointers to functions
- Modify values in-place
- Implement swap logic using dereferencing

---

# ⭐ Task 5: Null Pointer Check
## 🔍 Overview

This program declares a pointer and initializes it to nullptr, then checks whether it points to a valid memory location.

## 🎯 Objective

To understand the concept of null pointers and how to safely check pointer validity.

## ✔️ Output

Displays a message indicating whether the pointer is null or holds a valid address.

## ✍️ Learning Outcomes

- Use nullptr in pointer initialization
- Perform null checks using if (!ptr)
- Avoid invalid memory access

---

# ⭐ Task 6: Void Pointer Usage
## 🔍 Overview

This program demonstrates how to use a void pointer to store the address of an integer and access its value via typecasting.

## 🎯 Objective

To explore the flexibility and limitations of void pointers in C++.

## ✔️ Output

Displays the value of the integer using a typecasted void pointer.

## ✍️ Learning Outcomes

- Declare and assign void pointers
- Typecast void pointers before dereferencing
- Understand generic pointer behavior

---

# 🏠 Dynamic Memory Allocation
## 🔍 Overview

This task requires students to explore how pointers are used for dynamic memory allocation in C++ using the new and delete operators.

## 🎯 Objective

To allocate and deallocate memory at runtime using pointers.

## ✔️ Output

Allocates memory for an array or variable, accepts input, displays values, and frees memory.

## ✍️ Learning Outcomes

- Use new to allocate memory dynamically
- Use delete or delete[] to free memory
- Handle memory safely and efficiently
