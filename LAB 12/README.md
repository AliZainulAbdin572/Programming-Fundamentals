# 💻 CS-1101 Programming Fundamentals – Lab 11

This lab focuses on understanding and implementing functions in C++. Through six practical tasks, students will explore function declaration, calling, parameter passing, return values, and real-world applications using both user-defined and library functions.

---

# ⭐ Task 1: Using Library Functions
## 🔍 Overview

This program demonstrates the use of built-in C++ library functions to perform mathematical operations on a user-input number.

## 🎯 Objective

To familiarize students with standard library functions in C++.

## ✔️ Output

Displays the square root, absolute value, sine, cosine, and cube of the input number.

## ✍️ Learning Outcomes

- Use `<cmath>` library functions
- Perform mathematical operations
- Accept and process user input

---

# ⭐ Task 2: Greeting Message Function
## 🔍 Overview

This program defines and calls a function that displays a welcome message to the user.

## 🎯 Objective

To understand how to define and call a void function without parameters.

## ✔️ Output

Displays the message: “Hello, Welcome to C++ Functions!”

## ✍️ Learning Outcomes

- Define and call void functions
- Understand function structure
- Practice basic output formatting

---

# ⭐ Task 3: Even or Odd Checker
## 🔍 Overview

This program defines a function that checks whether a given number is even or odd using an if-else statement.

## 🎯 Objective

To practice conditional logic and function parameter passing.

## ✔️ Output

Displays “Even” or “Odd” based on the input number.

## ✍️ Learning Outcomes

- Use if-else statements inside functions
- Pass arguments to functions
- Apply modulus operator for logic

---

# ⭐ Task 4: Factorial Calculator
## 🔍 Overview

This program defines a function that calculates the factorial of a number using a loop and returns the result.

## 🎯 Objective

To implement iterative logic within a function and return computed values.

## ✔️ Output

Displays the factorial of the user-input number.

## ✍️ Learning Outcomes

- Use loops inside functions
- Return values from functions
- Handle integer calculations

---

# ⭐ Task 5: Menu-Driven Calculator
## 🔍 Overview

This program implements a simple calculator using functions for each arithmetic operation and a menu-driven interface.

## 🎯 Objective

To modularize arithmetic operations using functions and interact with users through a menu.

## ✔️ Output

Performs addition, subtraction, multiplication, or division based on user choice and inputs.

## ✍️ Learning Outcomes

- Use multiple functions in a program
- Implement menu-driven logic
- Perform arithmetic operations modularly

---

# ⭐ Task 6: Restaurant Billing System
## 🔍 Overview

This program calculates the total bill for a restaurant order using multiple functions for menu display, item cost calculation, and final billing with tax.

## 🎯 Objective

To design a modular program using multiple functions for a real-world billing scenario.

## ✔️ Output

Displays itemized order, subtotal, tax, and final bill.

## ✍️ Learning Outcomes

- Design modular programs using multiple functions
- Calculate totals and apply tax
- Use loops and conditionals for repeated user input
