# 💻 CS-1101 Programming Fundamentals – Lab 10

This lab introduces the concept of arrays in C++. Through six practical tasks, students will learn how to declare, initialize, traverse, and manipulate arrays using loops and built-in operators. Arrays are essential for handling collections of data efficiently, and this lab provides foundational skills for working with them.

---

# ⭐ Task 1: Initialize and Print an Array
## 🔍 Overview

This program initializes an array of five integers and prints each element using a loop.

## 🎯 Objective

To understand how to declare, initialize, and traverse an array using indexing.

## ✔️ Output

Displays all five elements of the array in order.

## ✍️ Learning Outcomes

- Declare and initialize arrays
- Use loops to access array elements
- Understand array indexing

---

# ⭐ Task 2: Print Array in Reverse Order
## 🔍 Overview

This program takes an array of N integers from the user and prints the elements in reverse order.

## 🎯 Objective

To practice user input, array traversal, and reverse indexing.

## ✔️ Output

Displays the array elements from last to first.

## ✍️ Learning Outcomes

- Accept array input from users
- Traverse arrays in reverse
- Apply loop control effectively

---

# ⭐ Task 3: Sum and Average of Array Elements
## 🔍 Overview

This program calculates the sum and average of all elements in a predefined integer array.

## 🎯 Objective

To perform aggregate operations like summation and averaging on array data.

## ✔️ Output

Displays the total sum and average of the array elements.

## ✍️ Learning Outcomes

- Use loops for summation
- Calculate averages
- Work with integer and floating-point data

---

# ⭐ Task 4: Find Length of an Array
## 🔍 Overview

This program determines the number of elements in an array using the `sizeof` operator.

## 🎯 Objective

To understand how to calculate array size in C++.

## ✔️ Output

Displays the total number of elements in the array.

## ✍️ Learning Outcomes

- Use `sizeof()` to compute array size
- Understand memory allocation in arrays
- Differentiate between total size and element size

## 🎯 Objective

## 🔍 Overview

This program demonstrates how to traverse an array and update specific elements using indexing.

To reinforce the concept of accessing and modifying array elements.

## ✔️ Output
