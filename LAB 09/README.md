# ⭐ Task 1: Print Numbers from 1 to N
## 🔍 Overview
●  The program asks the user to enter a number N.

●  It prints all numbers from 1 to N.

## 🎯 Objective
●  To understand the basic use of a while loop.

●  To perform counting using a loop.

## ✅ Output
●  Numbers from 1 to N will be printed.

## ✍️ Learning Outcome
●  Students will understand loop conditions and iteration.

# ⭐ Task 6: Password Validation Program
## 🔍 Overview
●  The program prompts the user to enter a password.

●  If the password is wrong, the program asks them to try again.

●  It repeats this until the correct password is entered.

## 🎯 Objective
●  To learn how to use the do-while loop.

●  To understand loops that must run at least once (exit-controlled loops).

## ✅ Output
●  Prompts for a password repeatedly until it matches the correct one.

●  Grants access only when the input is correct.

## ✍️ Learning Outcome
●  Students will understand how to secure a program flow using validation loops.

# ⭐ Task 7: Restaurant Ordering System
## 🔍 Overview
●  The user can select items from a main menu (Breakfast, Lunch, Dinner) and sub-menus.

●  Users specify the quantity they want (e.g., 2 KG of Chicken Karahi).

●  The program calculates the total bill based on fixed prices.

●  The user can keep ordering until they decide to stop.

## 🎯 Objective
●  To implement a complex system with nested menus and calculations.

●  To use a do-while loop for continuous ordering.

## ✅ Output
●  A menu display for food selection.

●  The final total bill amount to be paid by the user.
## ✍️ Learning Outcome
Students will learn to manage complex user inputs, calculations, and nested logic inside a loop.
